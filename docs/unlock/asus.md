# ASUS

Automated by the tool: no, guided.
Wipes data: yes.
Flash backend: fastboot.

## Steps

1. Enable OEM unlocking and USB debugging
2. Install the ASUS Unlock Device App for your model from the ASUS support site (ROG Phone and Zenfone). Older models accept fastboot flashing unlock
3. Run the app, accept the warranty void notice. Device wipes

## Notes

- ASUS discontinued the unlock app for several models in 2023. Check availability before buying into this path.
